# Ola Ride Demand Predictor

This project predicts Ola ride demand using Machine Learning based on time and weather conditions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI

## Model Evaluation
Mean Absolute Error (MAE): 21.78

## Sample Output
Predicted number of ride requests for Monday, 9 AM, 30°C, Sunny: 162

## How It Works
- Data preprocessing and feature engineering
- Model training and evaluation
- Predictions exposed via FastAPI backend
